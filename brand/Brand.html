One brand. A look per theme.

What stays the same whichever theme a product runs: the name and the mark, the voice, the icons. Each theme's brand book adds how that theme looks and moves, and links back here.

scnx-platform brand book scnx-saas brand book

This page covers

The identity: the name, the mark and its use, the voice and the copy rules, the icon grammar, and how themes, products and brand books relate. It is the one place these are written.

It does not cover

How a theme looks: shape, materials, lines, layout, type sizes, colour roles, motion. Those are in each theme's brand book. Token values belong to @scnx/system.

02 Name and mark
Minimum
20px
Clear space

A primitive, a component, and a verified check.

The mark is a 24px ink tile holding a primitive outline, a component square, a circle and a Scnx Blue check. It is artwork, not a component: no theme maps its shape, and its check is Scnx Blue in every theme, including scnx-saas.

03 Voice and copy
Case
sentence
Address
you

Plain, specific, and evidence-led.

State what is true and how it is verified: "Every release ships with the evidence that it works." "Static CSS and no style or script injected at run time, so a security team never loosens its policy."

01

Sentence case

Headings, buttons, menu items and table headers. An eyebrow's upper case is CSS, never typed.

02

Verbs on buttons

"Deploy", "New project", "Copy link", "Delete project". Never "OK", "Submit" or "Click here".

03

Speak to you

The product speaks for itself and rarely says "we": "Bring your brand, keep your stack, and verify every release you install."

04

Exact numbers

"3,200 / 5,000", "41 seconds", "128 deployments". Tabular figures wherever numbers update or align.

05

Errors say what to do

"Enter a full email address." "Add the TXT record and try again." No "Oops", no exclamation marks, no emoji.

06

Name the cost

Destructive copy names the object and the consequence: "Delete acme-dashboard?" "This removes 128 deployments, 3 domains and all environment variables. It cannot be undone."

04 Icons
Grid
24
Stroke
1.8

One grammar: a 24-unit grid and a 1.8 stroke.

Round caps and joins, currentColor, 16px in text and controls, 20px in large controls and navigation. The four contract marks carry one accent part in Scnx Blue. The set is the same in every theme.

Files are in design-system/assets/Icons/, single-ink for use as images; in code, draw them with currentColor. Stand-ins: the previews also draw x, chevrons, search, info, warning, plus, settings, user and others to the same grammar until the set ships them; never copy an icon from another library. An icon beside text is decorative (aria-hidden); an icon-only control needs an accessible name and, unless universal, a tooltip. Never use emoji as icons.

01

The prefix scnx- is ours

Only themes that @scnx/system ships are named scnx-*. A product's or a client's theme takes its own name, such as northwind, so it can never collide with a shipped one.

02

Named for whom, not for how

A theme is named after who owns the look, never after a trait. A trait name stops being true the day the theme maps another Tier-2 key. Mode (light, dark) is its own axis and never part of a theme's name.

03

A new look is a new theme

A product that needs a different look gets a theme, and that theme gets its own folder and brand book. A product never has a brand book of its own; product notes (terms, domain patterns, the hooks it sets) live in its repository and never change a theme's rules.
