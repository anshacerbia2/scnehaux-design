Control, in six rules.

01

Grey when normal

A panel with nothing wrong is grey: lamps lit grey, pipes grey. Colour is spent only on what needs a person, so it is seen at once. Blue keeps one meaning: here, and armed.

02

Annunciate, don't chart

A condition is a window that lights, with a count and what tripped it. The first to trip is first out. Every window opens the station that clears it. No figure is shown that nobody measured.

03

Mimic the path

The bus under the strip draws the path a request takes, browser to kernel, on every page. A degraded hop dashes in amber, so a failure says where before it says what.

04

Interlock, then execute

A command that changes a person sits behind a cover. Lifting it arms it and shows its interlocks: reason, recent sign-in, not yourself, a second operator where one is required. Execute is ink, never red.

05

Tag what you lock

Containment carries a lockout tag: who, since when, why, and what lifts it. A drift exception carries a bypass tag with its expiry. The state is never only a word in a badge.

06

Seal privileged reads, record to the millisecond

A read that is itself recorded is sealed until an operator breaks the seal on purpose. Every command, alarm and broken seal lands in the sequence-of-events recorder, in order, to the millisecond.
