Props

PROP TYPE DEFAULT BEHAVIOUR
variant 'primary' | 'secondary' | 'ghost' 'primary' Visual weight. Keep one primary per view.
size 'sm' | 'md' | 'lg' 'md' Control height 36 / 44 / 52. sm pads its hit area to 44px.
loading boolean false Shows a spinner, sets aria-busy, swallows clicks, keeps width stable.
disabled boolean false Native disabled. Prefer explaining why nearby over silently disabling.
iconStart · iconEnd ReactNode — Decorative icon slots, auto aria-hidden and sized from the size token.
asChild boolean false Render as your own element (e.g. a router link) while keeping styles and focus ring.
fullWidth boolean false Stretches to its container. Useful in mobile sheets.

INTEGRATE

From zero to themed in four steps

  1. 1Install
    Components and the token package, tree-shakable. pnpm add @acme/ui @acme/tokens
  2. 2Wrap your app
    One provider loads tokens as CSS variables. No runtime CSS-in-JS. <AcmeProvider theme="system">
  3. 3Bring your brand
    Pull tokens from Figma or override in code. Every component follows. npx acme tokens pull
  4. 4Connect your agents
    Coding agents read this documentation and build with real components. npx acme mcp add
