# Divider

Divider separates groups with a 1px hairline.

## Usage

- Provide `orientation` and `color` (`muted` default hairline `ds-color-neutral-border-subtle-default`, `default`, `primary`); a labelled divider centers an eyebrow between two lines.
- Prefer space and materials over dividers; one divider per boundary, never a box of dividers.

## Delta from the current build

- `thin` (0.5px) is retired: hairlines are 1px everywhere; margins move to the layout (no built-in margin).
