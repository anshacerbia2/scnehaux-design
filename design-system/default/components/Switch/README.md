# Switch

Switch turns a setting on or off immediately, with no save step.

## Usage

- Provide `children` (the label), `checked`, `onCheckedChange`; the input carries `role="switch"`.
- Track 36×20 pill; off is `ds-color-neutral-border-strong-default` (≥3:1 on the canvas), on is Scnx Blue; the 16px raised thumb slides in `ds-motion-feedback-duration`.
- If the change needs confirmation or a Save button, use a Checkbox instead.
