# Pagination

Pagination moves through pages of a long list or table.

## Usage

- Provide `page`, `pageCount`, `onPageChange` (or `href` per page) and a range summary ("Showing 21–40 of 128").
- Pages are 32px squares, radius element, tabular figures; the current page is the raised material (selection among peers), never blue. Previous and next are small ghost IconButtons.
