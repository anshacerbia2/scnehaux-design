# Spinner

Spinner says work of unknown length is in progress.

## Usage

- Provide `aria-label` (or place it inside a control whose label says what is loading) and `size` (16, 20, 36).
- A 2px ring in `ds-color-neutral-border-subtle-default` with a `currentColor` head, one turn per 0.8s; reduced motion slows it to 2.4s.
- Show it only after 400ms; a known quantity is Progress; a loading layout is Skeleton.
