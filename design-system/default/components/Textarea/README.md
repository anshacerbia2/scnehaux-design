# Textarea

Textarea is TextField's multi-line form: same label, description, error and boundary, at least 96px tall and vertically resizable.

## Usage

- Provide the same props as TextField; add `maxLength` to show a tabular `count` in the description row.
- Inline padding 12px, block padding 8px; never resize horizontally.
