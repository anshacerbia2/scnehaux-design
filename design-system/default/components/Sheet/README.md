# Sheet

Sheet slides a secondary task in from the end edge (or the bottom on mobile) while keeping the page in view.

## Usage

- Provide `side` (`end` default, `bottom`), `title`, body, and footer actions; a ghost close IconButton sits in the header.
- Sheet material: floating fill, radius panel 24 on the leading corners only, `ds-effect-material-sheet`; 384px wide (100% at bottom). Header and footer 16px/24px padding; the footer has a top hairline.
- Use for edit forms and detail panes; a short decision is a Dialog.
