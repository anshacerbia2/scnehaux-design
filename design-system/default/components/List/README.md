# List

List sets bulleted or numbered items with the system's rhythm.

## Usage

- Provide `variant` (`unordered`, `ordered`, `unstyled`), `spacing` (`compact` 4, `default` 8, `comfortable` 16) and `ListItem` children.
- Markers are subtle text; ordered lists use leading-zero mono numerals (01, 02), the eyebrow's voice.

## Delta from the current build

- Markers take the subtle text color; ordered markers become mono `decimal-leading-zero`.
