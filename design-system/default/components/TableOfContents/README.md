# TableOfContents

TableOfContents lists the headings of a long page and marks the section in view.

## Usage

- Provide the headings (`href`, `label`, nesting one level deep); the active item updates from scroll position.
- The eyebrow label "On this page", a 1px rail (`ds-color-neutral-border-subtle-default`), items at least 28px tall in subtle text; the active item is default text, medium weight, with a 2px Scnx Blue segment on the rail.

## Delta from the current build

- The label becomes an eyebrow; the active item gains the blue rail segment; links sit on a rail instead of free spacing.
