# Kbd

Kbd shows a keyboard key or shortcut.

## Usage

- Provide one key per Kbd (`children`); a chord is several Kbds with a 4px gap. Use platform glyphs (⌘ ⌥ ⇧) on macOS and words elsewhere.
- 20px keycap: mono 11px medium in subtle text, raised fill, radius mark 4, a hairline ring plus a 1px bottom edge. Inside a Tooltip it inverts to the tooltip's ink.
