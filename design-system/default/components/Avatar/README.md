# Avatar

Avatar stands for a person (circle) or an organization (square) with an image or initials.

## Usage

- Provide `name` (used for initials and `alt`), optional `src`, `size` (24, 32, 40) and `shape` (`circle` people, `square` workspaces and orgs).
- Initials: two letters, semibold, on `ds-color-neutral-surface-strong-default` with a hairline ring. Square radii follow size: mark 4, element 8, control 12.
- Groups overlap by 6px with a 2px canvas ring; a status dot is success-solid with a canvas ring.
