# Radio

Radio picks exactly one option from a small, visible set.

## Usage

- Provide a `RadioGroup` with `label` (a legend), `value`, `onValueChange`, and `Radio` items with `value`, label and optional `description`.
- 16px circle with the strong neutral boundary; checked fills Scnx Blue with a 6px dot in the contrast label color.
- Up to ~5 options; more is a Select. Two options that read as on/off are a Switch.
