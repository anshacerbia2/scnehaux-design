# Text

Text sets copy in one of the body or label styles.

## Usage

- Provide `variant` (`body-large`, `body-default` default, `body-small`, `label-default`, `label-small` uppercase), optional `weight`, `align` and `dimmed` (subtle text, never opacity).
- Inter with `cv11` (single-storey a) on; tabular figures for numbers that update.
- Mono uppercase metadata is the eyebrow (`.scnx-eyebrow`), not label-small.
