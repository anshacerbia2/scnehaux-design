# Progress

Progress shows how far a known quantity has gone: a 6px pill track with a Scnx Blue indicator.

## Usage

- Provide `value`, `max`, a visible `label` and a formatted value (tabular figures); `scheme` switches to `success` (complete) or `danger` (over a limit).
- Track `ds-color-neutral-surface-strong-default`, indicator `ds-color-primary-surface-solid-default`; width animates in `ds-motion-disclosure-duration`.
- Unknown duration is a Spinner.
