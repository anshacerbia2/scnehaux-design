# Checkbox

Checkbox toggles one independent option; checked is Scnx Blue.

## Usage

- Provide `children` (the label), `checked` / `defaultChecked`, `onCheckedChange`, optional `description` and `indeterminate`.
- 16px box, radius mark 4, `ds-color-neutral-border-strong-default` boundary on a raised fill. Checked and indeterminate fill with `ds-color-primary-surface-solid-default` and draw the mark in `ds-color-primary-text-contrast-default`.
- The native input stays in the DOM (visually hidden) so keyboard, forms and assistive tech work; the focus ring draws around the box.
- A list of mutually exclusive choices is Radio; an immediate on/off setting is Switch.
