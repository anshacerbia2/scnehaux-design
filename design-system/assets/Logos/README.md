The Scnehaux UI mark: two slanted bars, the upper one set to the right, 21 units wide to 9 high (the owner, 2026-10-29). `scnehaux-mark.svg`: bars #1d2024, for light grounds. `scnehaux-mark-inverse.svg`: bars #edeef0, for dark grounds. `scnehaux-mark-tile.svg`: the same bars in white on a black square, where a square is wanted (a favicon, an app icon). Minimum width 28px (the tile reads from 16px); clear space 4px.
